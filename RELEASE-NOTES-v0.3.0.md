# Release Notes – Beta v0.3.0

## Überblick

Beta v0.3.0 erweitert die deutsche Fan-Übersetzung von **Mystical Ninja Starring Goemon** deutlich um weitere Story-, NPC- und Systemtexte.

## Neu

- Yae-Beitritt und weitere Storysequenzen übersetzt
- zusätzliche NPC-Dialoge in späteren Gebieten
- Benkei-, Kihachi- und Ushiwaka-Dialoge erweitert
- Goldener Tempel und Trainingsdialoge ergänzt
- weitere Wegweiser, Hinweise und Systemtexte
- Humor und Wortspiele stärker an natürliches Deutsch angepasst

## Technisch

- insgesamt 1.294 Übersetzungssegmente
- 5.393 Textverweise geprüft
- 0 Scriptfehler
- 0 unbekannte Zeichen

## Hinweis

Die Übersetzung ist weiterhin eine Beta. Spätere Gebiete können noch englische oder unfertige Texte enthalten.

Keine ROM ist enthalten. Benötigt wird eine eigene legal erstellte Kopie der unterstützten US-Version.
