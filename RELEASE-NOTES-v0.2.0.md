# Goemon64 DE – Beta v0.2.0 🇩🇪

Die bisher größte Beta der deutschen Fan-Übersetzung für **Mystical Ninja Starring Goemon** unter **Goemon 64: Recompiled**.

## Neu in v0.2.0

- **927 Textsegmente** übersetzt
- davon **667 Einträge im frühen Oedo-Bereich**
- deutlich mehr frühe NPC-Dialoge
- Oedo-Stadt erweitert
- Torwächter und Polizisten
- erste Story-/UFO-Dialoge
- Speicher- und Ja/Nein-Texte
- Gegenstands- und Hinweistexte
- weitere frühe Tutorials

## Installation

1. `Goemon64-DE-Beta-v0.2.0.nrm` herunterladen.
2. Goemon 64: Recompiled starten.
3. **Mods → Mod installieren** öffnen.
4. `.nrm` auswählen.
5. Mod aktivieren.
6. Alte Versionen deaktivieren.
7. Goemon64Recompiled vollständig neu starten.

## Wichtig

Diese Version ist weiterhin eine **Beta**. Das gesamte Spiel ist noch nicht vollständig übersetzt und spätere Bereiche können weiterhin englische Texte enthalten.

Die Mod enthält **keine ROM**. Eine eigene, legal erstellte US-ROM von *Mystical Ninja Starring Goemon* wird benötigt.
