# Goemon64 DE – Beta v0.8.5

**Mystical Ninja Starring Goemon – Deutsche Fan-Übersetzung für Goemon 64: Recompiled**

Beta v0.8.5 ist der bisher umfangreichste öffentliche Stand der deutschen Übersetzung. Der vollständige geprüfte ROM-Textkatalog ist deutsch abgedeckt; zusätzlich wurde die Darstellung eng an die englische US-Originalfassung angeglichen.

## Highlights

- kompletter geprüfter Textkatalog auf Deutsch
- NPC- und Storydialoge mit sinngemäß übertragenem Humor und individuellen Figurenstimmen
- Menüs, Systemmeldungen, Shops, Gasthäuser, Speichertexte, Trainingsdialoge und Hinweise übersetzt
- originalgetreue Textfarben: **Gelb, Rot, Grün und Blau**
- farbige `[Klammern]`, Satzzeichen, Ellipsen und Apostrophe werden wie im Original berücksichtigt
- Auswahltexte und wichtige Begriffe vollständig eingefärbt, nicht nur teilweise
- Portrait-/Avatar-Textboxen übernehmen die Einrückungen des Originals, damit Text nicht hinter Portraits liegt
- zusammenhängende Dialogketten wurden auf doppelte oder abgebrochene Satzteile korrigiert
- kein ROM-Image im Release oder Repository enthalten

## Technische Prüfung

- 5.393 Textreferenzen geprüft
- 5.147 Übersetzungseinträge
- 1.931 Original-Farbspannen / 1.931 deutsche Farbspannen

- 327 Klammer-/Bracket-bezogene Farbspannen geprüft
- 5.655 Satzzeichen-/Klammer-Farbpositionen geprüft
- 0 abweichende Satzzeichen-/Klammer-Farbpositionen
- 0 Style-Code-Sequenzabweichungen
- 0 Farbgrenzen mitten in deutschen Wörtern
- 0 semantisch falsch platzierte Farbspannen
- 0 Scriptfehler
- 0 unbekannte Zeichen
- 0 sichtbare Textabweichungen

## Installation

1. `Goemon64-DE-Beta-v0.8.5.nrm` herunterladen.
2. **Goemon 64: Recompiled** starten.
3. **Mods** öffnen und die `.nrm` installieren.
4. **Deutsche Uebersetzung Beta v0.8.5** aktivieren.
5. Ältere Versionen der Übersetzungsmod deaktivieren.
6. Goemon64Recompiled vollständig neu starten.

Erforderlich ist eine eigene legal erstellte Kopie der unterstützten US-Version von *Mystical Ninja Starring Goemon*. Die ROM wird nicht bereitgestellt.

## Beta-Hinweis

Die Textabdeckung ist vollständig, die Versionsnummer bleibt jedoch bewusst **0.8.5 Beta**, weil weitere In-Game-Feinprüfungen möglich sind. Bitte melde falsch wirkende Formulierungen, Formatierungen, Textbox-Abstände oder noch auffällige Stellen mit Screenshot und Ort/Szene über GitHub Issues.
