# Fehlerbehebung

## Die Mod wird geladen, aber ich sehe keinen deutschen Text

1. Prüfe im Mod-Menü, ob **Beta v0.2.0** wirklich aktiviert ist.
2. Deaktiviere ältere Versionen wie v0.1.0 oder v0.1.1.
3. Beende Goemon64Recompiled vollständig und starte es neu.
4. Teste einen frühen NPC in Oedo-Stadt.
5. Prüfe, dass du die unterstützte US-Version des Spiels verwendest.

Die Beta ist noch nicht vollständig. Spätere Bereiche können weiterhin Englisch enthalten.

## Mod-Ladefehler

- Verwende die aktuelle Release-Datei und nicht eine alte Beta.
- Installiere die `.nrm` über den eingebauten Mod-Installer.
- Stelle sicher, dass keine zweite ROM-Patch-Mod gleichzeitig aktiv ist, wenn deine Runtime dies nicht unterstützt.
- Aktualisiere Goemon64Recompiled auf eine kompatible Version.

## Text ist abgeschnitten

Bitte erstelle ein Issue mit:

- Screenshot
- Ort / Szene
- aktuellem Text
- Mod-Version

Die N64-Texte besitzen feste Platzgrenzen; einzelne deutsche Sätze müssen eventuell kürzer formuliert werden.

## Umlaute fehlen

Die aktuelle Beta nutzt die ursprüngliche Zeichentabelle des Spiels. Deshalb werden in vielen Texten vorerst `ae`, `oe`, `ue` und `ss` verwendet.

## Ich habe einen Übersetzungsfehler gefunden

Nutze auf GitHub **Issues → Übersetzungsfehler** und gib die betroffene Stelle möglichst genau an.
