# Installation – Schritt für Schritt

## 1. Aktuelle Mod herunterladen

Öffne auf GitHub den Bereich **Releases** und lade die neueste Datei mit der Endung `.nrm` herunter.

Für Beta v0.2.0 lautet sie:

`Goemon64-DE-Beta-v0.2.0.nrm`

## 2. Goemon 64: Recompiled starten

Starte deine installierte Version von **Goemon 64: Recompiled** und stelle sicher, dass deine eigene US-ROM bereits korrekt eingerichtet ist.

## 3. Mod-Menü öffnen

Öffne im Launcher bzw. Hauptmenü den Bereich **Mods**.

## 4. Mod installieren

Wähle **Mod installieren** und anschließend die heruntergeladene `.nrm`-Datei.

## 5. Mod aktivieren

Aktiviere:

**Deutsche Uebersetzung (Beta v0.2.0)**

## 6. Alte Versionen deaktivieren

Falls du eine ältere Beta installiert hast, deaktiviere sie. Es sollte immer nur die aktuelle Übersetzungsmod aktiv sein.

## 7. Anwendung neu starten

Beende Goemon64Recompiled vollständig und starte es erneut.

## 8. Übersetzung testen

Sprich im frühen Oedo-Bereich mit NPCs. In Beta v0.2.0 sind dort zahlreiche Dialoge bereits auf Deutsch.

Wenn weiterhin alles Englisch ist, lies [TROUBLESHOOTING.md](TROUBLESHOOTING.md).
